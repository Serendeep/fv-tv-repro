# Gemma and sentiment extension results

The archive contains 96 completed cells:

| Directory | Coverage | Cells |
|---|---|---:|
| `gemma_tv/` | Base/IT Gemma, eight tasks, three seeds | 48 |
| `gemma_fv/` | Base/IT Gemma, two tasks, three seeds | 12 |
| `gemma_sentiment/` | Base/IT Gemma, three mappings, three seeds | 18 |
| `sentiment_ndif/` | GPT-J/Llama, three mappings, three seeds | 18 |

Each arm includes partitions, a manifest, and a hashed source snapshot. Each cell
includes token predictions and development-selected layers. FV cells also retain
mean activations, AIE scores, and constructed vectors for inspection of the null
result. TV tensor caches are omitted; saved predictions suffice for table
regeneration, and the archived source reconstructs vectors with model access.

`provenance/` records the Kaggle source bundles, execution checks, and the bounded
NDIF/Kaggle TV comparison. These scientific records describe the executed
protocol; operational logs and working notes are kept outside the public repo.
`summary.json` and five LaTeX tables are generated by
`scripts/extension_paper_tables.py`. Run it with `--check` to verify the archive
and detect stale outputs.

The eight-task Gemma TV comparisons use paired task-bootstrap intervals after
averaging seeds. Sentiment comparisons average seeds and mappings within input
before stratified input resampling. These intervals condition on the fixed
construction choices. The two-task FV check has no task-population interval.
